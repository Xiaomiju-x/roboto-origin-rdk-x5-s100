- [x] 未修改 Wi-Fi、路由、VPN、TUN、ARP、固定 IP、SSH 或 VNC。

## G2：硬件和电气检查

- [ ] 机器人有可靠支撑/安全吊架，活动范围内无人和易损物。
- [ ] 物理急停、主电断开和软件停机路径均由现场人员验证。
- [ ] 电池/电源型号、额定电压、极性、保险和接地已确认。
- [ ] 每个待测执行器的型号、额定电压、节点 ID、协议、波特率和机械零位已记录。
- [ ] CAN_H、CAN_L、GND、端接电阻和四路总线映射经实物核对。
- [ ] 线束无裸露、反接、松动、夹压或超过弯曲半径。
- [ ] 首次运动对象已可靠固定或脱离负载。
- [ ] 现场有一名独立人员负责急停/断电，操作人与急停人员口令一致。

## G3：无使能通信检查

- [x] 只读枚举 CAN/USB/串口名，不执行官方文档中的 udev 或系统配置修改；`can0` 始终保持 `DOWN/STOPPED`。
- [ ] 只读读取设备身份、错误码、温度、电压和位置，确认无节点 ID 冲突。
- [ ] IMU 单位、坐标系、频率和静止偏置合理。
- [ ] 控制器在状态丢失、时间戳陈旧、NaN/Inf 或频率异常时拒绝输出。
- [ ] 日志目录、配置快照和测试编号已创建。

## G4：首次动作批准

执行前必须再次获得用户对“单执行器小幅运动测试”的明确确认，并固定以下限制：

- 电流、速度、转矩、角度和持续时间均采用保守值；具体值基于电机铭牌/手册，不凭猜测填写。
- 先验证软件停机，再由急停人员确认物理急停可达。
- 每次只改变一个变量；单次动作后回到失能状态并检查温度、错误和机械位置。
- 禁止直接全关节、大幅度、高速度、高转矩、负载行走或自动恢复动作。

## 门禁结论

只要任一必选项不确定，结论即为 `BLOCKED`；不得用软件绕过硬件缺失、急停缺失或实物信息不清。
