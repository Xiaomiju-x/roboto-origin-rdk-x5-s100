# XRD 外部只读开源快照参考映射

该目录是冻结 XRD 资产，只读参考。本轮只使用其中的公开发布快照
`open_source_release_work/xrd-top-release`；该快照实测为干净 Git 工作树，锁定提交
`6c150dc3ea964b0617ede87f5b76a928876c693b`。XRD 根目录的其他凭据、认证、私有数据、
模型和日志目录均不进入盘点。本项目不运行、修改或复制其中的服务、固件、模型、地图、日志和大数据。

## 可借鉴内容

| 参考目录 | 可借鉴模式 | 不直接复用的原因 |
| --- | --- | --- |
| `finals_successor` | 多帧 BEV、未来占据/流、动态和不确定性、ShadowGuard | 原输入、机器人几何和验证对象不同；X5 BPU 仅做过固定输入接受性验证 |
| `finals_vnext` | 传感器健康、来源标签、TTC、跟踪、可靠性 | 指标多为合成/缓存数据，且面向原 XRD 导航栈 |
| `finals_cortex` | 只读记录器、时间同步、完整性、候选评估、校准/OOD/漂移、稀疏记忆 | 当前为离线监控框架，不能直接作为人形控制安全证明 |
| `ros2_ws/src/my_robot_navigation` | SLAM/Nav2/MPPI/EKF、碰撞监控、影子规划器接口 | 冻结且偏轮式机器人；足式动力学、足迹和控制链路不同 |
| `my_robot_perception` | YOLO-World/EdgeSAM 启动脚手架 | 属算法升级候选，不是 RoboParty 官方视觉基线 |
| `x5_repurpose_20260825` | X5 隔离合同、路径与恢复边界 | 只继承边界，不恢复冻结服务 |

## 建议升级顺序

1. 首先移植“只读记录、时间同步、来源标注、健康度”这些低耦合能力。
2. 再将未来占据/动态/TTC 作为导航或运动策略的影子评估输入，不直接接管控制。
3. 使用 Trust/OOD/漂移输出收紧速度和策略选择；需要明确故障时的确定性降级动作。
4. 只有在离线回放、仿真和受控台架均通过后，才允许候选模块进入实机控制路径。
