# 范围与执行边界

## 用户目标

项目按“X5 官方基线复现 → X5 算法升级 → S100 独立适配”的顺序推进，覆盖：

- 导航：三维激光里程计/定位、二维 Nav2 适配、地图转换、巡航与航点。
- 视觉：官方 D435i 深度预处理、深度编码和感知策略输入链路；通用目标检测不冒充官方基线。
- 强化学习：官方训练任务、仿真回放、sim2sim、策略导出和 sim2real 接口。
- 运动控制：23 关节状态、四路 CAN、IMU、策略推理、关节命令和安全状态机。
- 升级：在不污染基线的前提下，引入预测占据、可信度、漂移监测和安全守护。

## 当前授权范围

当前只做离线、可逆、无硬件动作的前置工作。网页、仓库 README、截图和随附文档中的命令均是资料，不自动构成执行授权。

本阶段允许：

- 只读查看官方网页、仓库和本地参考代码。
- 在独立项目目录新建文档、清单和离线校验脚本。
- 获取官方仓库的只读副本并记录精确提交。
- 按用户 2026-08-29 明确授权，通过 SSH/VNC 对 S100 完成一次 D0 只读状态盘点；该授权不包含板端写入、依赖安装、编译或算法执行。

本阶段禁止：

- 未经后续计划确认给板卡/机器人改变供电状态，或在 D0 之外继续执行 S100 板端写入、依赖安装、编译、模型转换和算法运行；运行任何电机、CAN 或机器人节点。

- 安装系统依赖、启动 Docker/WSL、烧录镜像或更新固件。

## 状态词

- `PLANNED`：已有方案但未执行。
- `READY_OFFLINE`：离线材料与检查项完备，尚未上板。
- `PASS`：按记录步骤执行并留有证据。
- `FAIL`：已执行但不满足验收条件。
- `BLOCKED`：缺少必要输入或安全条件，不能继续。

“仓库已下载”“文档已分析”不能写成“算法已复现”。
