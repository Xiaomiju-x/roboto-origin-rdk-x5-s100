# 公共发布策略

公共仓库是项目自有代码、复现合同与脱敏证据的长期维护面；完整原始机器证据继续保留在受控本地交付面。

## 公布

- `src/`、`probes/`、`scripts/` 下的项目自有实现；
- `patches/` 中可审计的上游补丁；
- `config/`、`inventory/`、`requirements/` 中的版本、哈希、许可证与部署决策；
- 复现、安全、结果、路线图与阶段文档；
- 不含网络端点和个人路径的机器摘要。

## 不公布

- 凭据、Token、API Key、密码、私钥和账户材料；
- 私网 IP、MAC、Wi-Fi、内部主机名、个人绝对路径；
- 完整原始日志、设备序列号与网络快照；
- 未允许再分发的模型、数据、HBM/BIN、Docker 镜像或第三方源码；
- 缓存、构建目录、虚拟环境、训练运行和上游检出。

不公布原始证据不降低状态诚实性：公开摘要保留结果、门、哈希、阈值和局限；如需审查完整证据，应通过维护者的受控披露流程，并再次检查第三方许可证和隐私边界。
